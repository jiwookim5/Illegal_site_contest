## 정답 파일 구성과 상태

| 목록 | 잡힌 것으로 보는 기준 | `status` |
|---|---|---|
| `answers` | url·위치·기법이 모두 맞는 주요 유형 검출 | `detected` / `known_gap` |
| `other_answers` | 그 요소를 주요·추가 유형 어느 쪽으로든 보고 (4종 가운데 분류가 정해지지 않음) | `detected` / `known_gap` |
| `traps` | 주요 유형 검출이 **없어야** 함. `location`이 없으면 그 주소의 검출 전부가 오탐 | `ok` / `known_fp` |

`evasion_check.py`는 상태와 실제 결과를 비교합니다.

- `detected`인데 놓침, `ok`인데 오탐 → **실패** (회귀·새 오탐)
- `known_gap`인데 잡힘, `known_fp`인데 오탐 없음 → **개선**으로 알림
- 정답·함정 어디에도 없는 주요 유형 검출 → 언제나 실패

탐지를 고쳐서 개선이 나오면 `--sync`로 상태를 고쳐 쓰고 코드와 함께 커밋합니다.

```powershell
.venv\Scripts\python tools\evasion_check.py --sync
```
