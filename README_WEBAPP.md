# 🚨 IP 불법광고 탐지 웹앱

IP 주소를 입력하면 웹 서버의 텍스트를 크롤링하여 **불법광고(도박, 성인, 마약)**를 탐지하는 웹 애플리케이션입니다.

---

## 📋 기능

✅ **IP 기반 웹 크롤링**
- IP:Port 조합으로 웹 서버 접근
- 텍스트 추출 및 분석

✅ **불법광고 자동 탐지**
- 도박 (토토, 바카라, 슬롯 등)
- 성인 (야동, 포르노 등)
- 마약 (대마, 코카인 등)

✅ **보안 검증**
- 로컬 IP(127.0.0.1, 192.168.* 등) 차단
- 타임아웃/연결 실패 처리

✅ **직관적인 UI**
- 실시간 결과 표시
- 탐지 키워드 목록 표시
- 모바일 반응형

## 💻 사용 방법

### 기본 사용

```
1. IP 주소 입력 (예: 8.8.8.8)
2. 포트 입력 (기본값: 80)
3. [스캔] 버튼 클릭
4. 결과 확인
```

### 테스트 IP 예시

```
8.8.8.8       → Google DNS (불법광고 없음)
1.1.1.1       → Cloudflare DNS (불법광고 없음)
example.com   → 도메인도 가능 (DNS 해석됨)
```

### 결과 해석

| 상태 | 의미 |
|---|---|
| ✅ 불법광고 없음 | 탐지 키워드 미발견 |
| 🚨 [카테고리] 탐지 | 불법광고 발견 (도박/성인/마약) |
| ⚠️ 로컬/차단 IP | 127.0.0.1, 192.168.* 등 |
| ❌ 연결 실패 | 해당 IP 서버 오프라인 |

## 🐛 문제 해결

### Port 5000 이미 사용 중인 경우

```bash
# 포트 변경 (app.py 마지막 줄 수정)
# port=5000 → port=8000 등

# 또는 기존 프로세스 종료
lsof -ti:5000 | xargs kill -9
```

### IP 연결 실패

```
원인: 해당 IP 서버가 오프라인이거나 방화벽이 차단함
해결: 공개 IP(예: 8.8.8.8) 테스트해보기
```

### 한글 텍스트 깨짐

```
자동으로 UTF-8로 처리됩니다.
문제 시 브라우저 인코딩 확인: Ctrl+Shift+X → UTF-8
```
