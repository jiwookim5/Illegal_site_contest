# 광고탐지 오탐·미탐 조사와 개선 방향 (2026-10-19)

## 조사 범위와 판정 기준

현재 워크스페이스의 **소스 코드**와 개발용 시험 자료를 검토했다. 실제 공공기관 누리집은 점검하지 않았다. 로컬 시험의 정답은 개발 중 작성된 것이므로 운영 오탐률·미탐률로 해석할 수 없다. 작업 트리에 기존 수정 사항이 있어 이 문서는 그 수정 사항이 반영된 현재 소스를 기준으로 한다. 배포된 `훤히.exe`에 같은 변경이 들어 있는지는 별도 확인이 필요하다.

오탐은 정상 내용을 위반 광고로 확정한 경우, 미탐은 실제 광고가 결과에서 빠진 경우로 정의한다. `검토 후보`는 확정 전 담당자 검토 대상이며, 제출용 `result.json`·`result_extra.json`에는 들어가지 않는다. 따라서 후보가 실제 광고인지는 원문 검토로 판정하고, 후보가 있다는 사실을 확정 탐지와 혼동하지 않아야 한다. 페이지 미방문·검사 미실행·OCR 불가도 문구 판정 미탐과 별도 집계한다.

## 현재 방식

1. `scan.py`가 진입 주소에서 링크·프레임·화면 전환을 탐색하고, 실패·남은 주소를 `scan_coverage.json`에 기록한다. 기본 페이지 상한은 5,000개이며 GUI는 회차별 시간 한도를 선택한다.
2. `extract_js.py`·`findings.py`가 DOM의 글과 스타일을 읽어 닮은꼴 문자, 자모 분해, 투명 글자, 화면 밖 은닉 4종을 판정한다. GUI 기본 설정은 이 4종이다. 메타·속성·링크·노출 광고, 첨부파일, 그림 OCR, 검색창, 연계 링크, 크롤러 위장 검사는 선택 사항이다.
3. `normalize.py`가 문자 위장과 구분자를 정규화하고, `lexicon.py`가 업종·품목·거래·연락처 근거를 점수화한다. `precision_policy.py`가 문장 거리, 정상 안내·보도 문맥, 애매한 업종 표현을 다시 판단해 광고·검토 후보·정상으로 나눈다. 점수는 확률이 아니다.
4. 최근 작업 트리의 띄어쓰기 경계 보정은 `가입 플랜`→`입플`, `코카 인형`→`코카인` 같은 우연한 결합을 제외하고, `졸피뎀구매`처럼 붙은 거래 표현을 보강한다. `report.py`는 검토 후보를 제출 위반 항목에서 제외한다.

Google은 해킹된 사이트에서 숨긴 링크·글, 새 스팸 페이지, 검색엔진과 사용자에게 다른 내용을 보여 주는 위장 사례를 설명한다. 따라서 DOM 한 번의 정상 조회만으로 음성 판정을 확정하지 않도록 색인 주소·보안 이슈·서버 기록과 대조하는 운영 절차가 필요하다. 참고: [Google 검색 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies), [사용자 생성 스팸 방지](https://developers.google.com/search/docs/monitor-debug/prevent-abuse).

## 개선 순서

1. **운영 판정 자료 만들기.** 허가된 기관의 기존 신고·삭제 이력과 관리자 검토 결과에서 광고·정상·보류 사례를 수집한다. URL, 수집 시각, 원문 문장, DOM 위치, 매체(본문·메타·그림·첨부), 사이트 유형, 판정 근거를 보존하되 연락처 등 개인정보는 평가용 사본에서 가린다. 개발 자료와 평가 자료를 분리하고, 분쟁 사례는 두 명 이상이 재검토한다.
2. **오류를 발생 단계별로 분해하기.** 미탐을 `주소 발견 실패 → 방문 실패/한도 → 내용 추출 실패 → 정규화·사전 누락 → 문맥 판정 제외 → 후보 미처리 → 내보내기 제외`로 분류한다. 오탐은 `우연한 문자열 일치 → 문맥 오해 → 중복 위치/유형 → 정답 기준 오류`로 나눈다. 이 분류와 점수 `trace`, 원문 증거를 한 건씩 연결한다.
3. **낮은 위험의 운영 개선부터 적용하기.** 결과 화면에 검사 종류별 `실행/미실행/일부 완료/불가`와 후보 미검토 수를 한눈에 표시한다. `검출 0건`인 경우에도 미방문 주소·실패·OCR 불가가 있으면 완료 판정 문구를 쓰지 않는다. 후보 검토 결과를 다음 회귀 자료에 반영한다.
4. **판정 규칙은 사례 쌍으로 보정하기.** 동일 단어의 정상/광고 최소 쌍을 만들고, 거래 행위·연락처·목적지·노출 위치가 가까운지 확인한다. 단순 임계값 변경이나 사전 단어 추가보다 실제 광고의 근거 조합을 규칙으로 추가한다. `가입 플랜`과 `가입 보너스`, `졸피뎀 구매 시 처방전`과 `졸피뎀구매`를 함께 회귀 검사한다.
5. **선택 검사와 범위 공백을 줄이기.** 기관의 게시판 운영 형태에 맞춰 추가 유형·첨부·OCR·색인 목록·위장 검사를 점검 계획에 명시한다. 한도에 걸린 그림·파일은 다음 회차에 이어서 처리할 수 있는지 검증하고, 남은 항목 수를 결과에 표시한다. 인증이 필요한 영역이나 검색에만 노출되는 주소는 관리자 제공 주소 목록과 대조한다.
6. **배포 전 검증하기.** 사이트 단위로 분리한 보류 평가셋에서 확정 광고의 정밀도(TP/(TP+FP)), 재현율(TP/(TP+FN)), 후보 포함 재현율, 매체별·기관별 수치, 방문/추출/검사 완료율을 따로 보고한다. 동일 URL·위치·유형 기준으로 중복을 제거하되 서로 다른 URL의 실제 광고는 유지한다. 소스와 배포 EXE를 같은 정답으로 비교하고, 개선 전후의 오탐·미탐 목록을 모두 공개한다.

### 빠진 근거

1. **내용 추출 실패(조용한 미탐).** 페이지가 브라우저 기본 `Map`을 덮어쓰면 Playwright가 돌려주는 객체·배열이 모두 `None`이 되어, 점검이 멈추거나 추출 글이 빈 채로 넘어갔다(gb.go.kr 재난안전대책본부 페이지에서 발생). 위 분류의 `내용 추출 실패`에 해당하는 가장 위험한 미탐 유형이다. 같은 날 고쳤다(`detector/browser.py`).
2. **은닉 오판.** gb.go.kr 문서 뷰어(시냅)의 채용 신체검사서 '마약류 검사 필로폰 대마 케타민 엑스터시 코카인 아편'이 화면 밖 은닉 광고로 확정됐다. 뷰어가 쪽 그림 위에 글자 크기 0 글자층을 겹쳐 두는 구조를 숨긴 글로 본 것이다. 위 오탐 분류(우연한 문자열 일치·문맥 오해 등)에는 이 단계가 없으므로 `은닉 오판`을 추가한다.
3. **점수 규칙과 화면 설명의 불일치.** 키워드 화면은 품목(MEDIUM) 낱말이 판매·연락처 같은 단서가 붙어야 광고라고 설명하지만, 실제 점수는 품목 낱말만 넷이어도 1.5점으로 기준을 넘었다(위 신체검사서 사례).
4. **감점 단어 확대의 부작용.** 의료 안내 낱말(처방·진료비·비급여·전문의약품·검사)을 정상 문맥 근거로 넣는 실험에서, 의료 문맥 오탐 3건은 사라졌지만 실제 광고 미탐이 숨김·보임 판정 152개 중 7개에서 13개로 늘었다. 불법 의약품 광고가 '처방전 없이'를 쓰고, 유흥 광고의 '유흥검사바로가기'가 '검사'로 감점됐다. 위 4번 '사전 단어 추가보다 근거 조합'의 실제 근거다. (첫 실험은 오탐 방지 키워드 목록에 낱말을 넣지 않아 감점이 걸리지 않았다. 고쳐서 다시 돌린 값이다.)
5. **현재 규칙으로 못 잡는 미탐 유형.** 연락처가 없는 의약품 판매 광고('비아그라 처방전 없이 정품 최저가' 등 5문구)는 숨김·보임 모두 놓친다. 거래 표현이 사전에 없는 말('최저가', '처방 없이')이다. 의료 낱말은 위 4처럼 양쪽으로 작용하므로 독립 검증 자료가 생긴 뒤 다룬다.

### 개선 순서에 대한 검수 의견

- 1번(기관 신고·삭제 이력)은 기관 협조와 개인정보 처리가 필요해 당장 할 수 없다. 먼저 개발 단계에서 실제 누리집을 점검하고 나온 검출을 개발자가 직접 검토한다(위 은닉 오판을 찾은 방식).
- 2번 단계 분해는 바로 쓸 수 있다. 판정 내역(`trace`)과 점검 범위 기록이 이미 있다. 오탐 분류에 `은닉 오판`, 미탐 분류의 `내용 추출 실패`에 '브라우저 결과 전달 실패'를 명시한다.
- 3번 운영 화면 개선과 담당자 라벨링은 하지 않는다. 이 프로그램은 탐지 도구이므로 정확도 측정은 개발 과정의 일이고, 담당자에게 정답 표시를 맡기지 않는다. 기존 '오탐 처리' 상태는 그대로 둔다.
- 미탐은 결과 화면에 나올 수 없으므로 화면 밖에서 잰다: 정답이 있는 시험 사이트, 개발에 쓰지 않은 실제 광고 문구 모음, 검색엔진에 색인된 스팸 페이지와 점검 결과의 대조(기존 검색엔진 보조탐색·색인 목록 점검 활용).
- 6번 지표에는 표본 크기를 함께 적는다. 정상 300건에서 오탐 0건이어도 95% 신뢰 상한은 약 1%이므로, '오탐 0건'을 '오탐률 0%'로 쓰지 않는다.
