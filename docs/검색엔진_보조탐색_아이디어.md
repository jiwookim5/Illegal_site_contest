# 검색엔진 보조 탐색과 색인삭제 지원

기존 수집기와 탐지엔진이 광고를 충분히 발견하지 못했을 때 담당자가 추가로 실행하는 기능이다. 구글에서 `site:{타깃 도메인} {광고단어}`를 검색하고 (처음에는 네이버·다음도 검토했으나 지금은 구글만 지원한다), 결과 URL을 기존 탐지엔진으로 재검사한다.

## 창의성과 독창성 설명

사이트 내부 탐색과 외부 검색 노출을 대조하여 내부 링크로 발견하기 어려운 광고와 삭제 후 검색에 남은 흔적까지 관리한다. 단순 검색 자동화보다 발견, 재검증, 담당자 조치 근거 제공을 연결하는 것이 핵심이다. 최초·유일한 기술이라는 주장은 별도 선행 사례 조사 없이 하지 않는다.

발표 문장: “기존 웹사이트 내부 탐색에 검색엔진 기반 외부 탐색을 결합하여 탐지 사각지대를 보완한다. 검색 결과와 실제 페이지 상태를 대조해 광고 게시물, 검색어 반사형 광고, 삭제 후 검색에 잔존하는 URL을 구분하고 담당자의 색인삭제 요청에 필요한 근거를 제공한다.”

## 필요한 처리

- 검색엔진, 검색어, 검색 시각, 검색 결과 URL·제목·요약을 보존한다.
- 원본 URL의 파라미터를 제거하거나 합치지 않는다. 파라미터에 삽입된 문구 자체가 증거일 수 있다.
- 현재 광고 탐지, 파라미터 반영, 파라미터 문구만 존재, 삭제 응답, 삭제 안내 의심, 현재 광고 미탐지, 확인 불가를 구분한다.
- 검색 결과의 광고 단어만으로 위법성을 확정하지 않는다. 예방 안내·뉴스 등은 담당자가 검토한다.
- 403·429·시간 초과는 삭제가 아니다. 200 응답의 삭제 안내도 확정 삭제와 구분한다.
- 검색 당시 노출과 현재 상태를 비교하는 자료를 내보낸다. 색인삭제 요청과 최종 판단은 담당자가 수행한다.

## 제출본 연결

`detector/search_assist.py`가 추가 실행 도구이며 `detector/search_discovery.py`에서 수집·재검사·내보내기를 처리한다. 재검사는 제출본의 `BrowserSession`, `walk_frame`, `classify`를 재사용한다. 실행 방법과 제한은 `검색엔진_보조탐색_사용법.md`를 참고한다.
