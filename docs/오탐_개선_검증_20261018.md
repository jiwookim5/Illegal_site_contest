# 오탐 감소 정책 변경 및 검증

## 적용 내용

1. 주소·연락처의 존재와 광고 유도를 구분한다. 예방·독서·상담 등의 정상 문맥에 참고 주소나 카톡 언급만 붙은 경우 광고로 확정하지 않는다. 개인 연락처까지 있는 정상 문맥은 검토 후보로 보존한다.
2. 일반 홍보어 가점은 최대 두 개로 제한한다. 가입 보너스·쿠폰 지급·판매·충전 등의 구체적인 유도는 별도 근거로 유지한다. 재택부업·백링크 등 정상 용도가 있는 범용 표현만으로는 광고를 확정하지 않는다.
3. 문장 경계와 정규화된 글에서의 근거 거리(80자)를 확인한다. 다른 문장의 단서를 합쳐야 기준을 넘는 경우 검토 후보로 남긴다. 안내문 옆의 독립적인 광고 문장은 유지하며, 정상 문맥으로 제외된 숨김 글을 조각 판정으로 다시 확정하지 않는다.
4. 검토 후보를 광고 판정과 분리한다. 결과 목록·필터·상세·보고서·CSV·실행 기록에 보존하고 제출용 `result.json` 및 `result_extra.json`의 위반 항목에서는 제외한다. 같은 위치에서 후보와 광고 근거가 모두 수집되면 광고 근거를 우선한다.

기존 실행 기록은 다시 판정하지 않는다. 조치 상태 변경은 후보의 제출 승격을 뜻하지 않는다. 실행 파일은 이 작업에서 재빌드하지 않았다.

## 검증 결과

- 실제 광고 예문 73건 및 정상 예문 69건: 기대 판정과 불일치 0건. 기존 미탐 목록 3건은 별도로 유지한다.
- 복합 합성 자료: 정상 51개에 대해 주요·추가 유형 오탐 0건, 광고 6개 모두 검출. 입력 원본 변경 없음.
- 일반 시험 사이트: 채점 대상 주요 정답 101건 모두 검출. `testsite4`의 슬롯 쿠폰 문구는 보완 후 별도 재실행으로 10/10 확인했다.
- 추가 유형 검출 건수는 기존 기준과 같다. OCR 시험 사이트도 실행되어 추가 유형 5건을 기록했다. 이 숫자가 모든 OCR 상황의 정확도를 보장하지는 않는다.
- 새 정책 검사 8개, 문맥 검사 13개, 탐지 회귀 검사 11개, 저장 검사 26개, 결과 UI 검사 10개, 엔진 검사 9개, 글꼴·canvas·느린 응답 검사 7개 통과.
- UI 이력, 요청 보호, 중지 UI, 키워드 UI, 기존 우회 회귀 검사도 실행해 통과했다.
- 우회 사이트 최종 재검사: 145/145 검출, 정상 함정 오탐 0/46, 종료 코드 0. 초기 검증에서 후보로 내려가거나 정상 문맥으로 잘못 제외된 5건은 콘텐츠 접속 유도, `자기소개서`와 `기소`의 부분 문자열 충돌, 실제 글꼴 치환 근거를 구분해 해결했다.

전체 실행 로그에는 보완 전 `testsite4` 미탐 1건이 남아 있으며 별도 재검사에서 해결했다. 보완 후 재검사도 오래된 `baseline.json`과 CSS 선택자 표기가 달라 종료 코드 1을 반환한다. 주요 정답은 실제 요소를 해석하는 채점으로 확인했으며, 기준 파일을 덮어써 통과 처리하지 않았다. `testsite12`는 기준의 3건과 달리 현재 정답 5건을 검출한다. 따라서 전체 회귀 명령 자체를 무조건 통과한 것으로 표현하지 않는다.
