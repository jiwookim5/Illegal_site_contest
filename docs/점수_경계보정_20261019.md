# 판정 점수 경계 보정 보고

## 배경

점수 계산은 공백과 구분자를 지운 정규화 글에서 사전 낱말을 부분 문자열로 찾습니다. 이 때문에 이웃한 두 낱말의 일부가 합쳐져 은어·품목 낱말이 되는 오탐이 있었습니다. 예를 들어 '가입 플랜'은 입플, '첫 충전'은 첫충, '코카 인형'은 코카인, '출장 오피스'는 출장오피로 맞춰졌습니다. 이런 문구는 화면에 보이는 글 기준으로도 광고로 확정되었고, 은어(STRONG)에 연락처가 붙으면 '확실' 등급까지 나왔습니다. 기존 시험 자료에는 이런 정상 문구가 없어 회귀 검사로는 드러나지 않았습니다.

## 변경 내용

1. **띄어쓰기 경계** (`lexicon._token_spans`, `_accidental`): 원문의 띄어쓰기 단위 낱말이 정규화 글에서 차지하는 구간을 구합니다. 사전 낱말이 이웃 낱말의 **일부만** 끌어다 맞춰진 경우는 세지 않습니다.
   - '출장 안마', '토토 사이트', '먹 튀', '카 지 노'처럼 낱말 전체가 모여 사전 낱말이 되면 띄어 쓴 광고로 보고 계속 셉니다.
   - 남는 글자가 사전 낱말·'사이트'·숫자로 이어지면('안전 놀이터추천') 광고가 붙여 쓴 꼬리로 보고 셉니다.
   - 자모를 띄어 쓴 위장처럼 낱말별 정규화 결과가 전체와 맞지 않으면 경계를 따지지 않습니다. 위장 글을 놓치지 않는 쪽을 택한 것입니다.
2. **일상어 꼴 품목** (`lexicon.EVERYDAY`): 작대기, 현금화, 스테로이드, 레플리카, 대량판매, 상품권매입이 대상입니다. 이 낱말은 거래 표현이 바로 붙었거나('작대기팝니다') 연락처·문자 위장이 함께 있을 때만 품목으로 셉니다. 사람찾기·라방 같은 BROAD 낱말은 기존대로 검토 후보로 남깁니다.
3. **붙여 쓴 거래 표현 가점** (`lexicon.ATTACHED_W = 0.15`): 품목 낱말 바로 뒤에 같은 낱말 안에서 거래 표현이 붙으면('졸피뎀구매') 가점을 줍니다. 예방 문구가 있으면 주지 않고, 띄어 쓴 안내문('졸피뎀 구매 시 처방전')에도 주지 않습니다.
4. **점수 내역** (`detail["trace"]`): 기본 점수, 가점, 정상 문맥 감점, 상한, 일반 홍보어 제한을 차례로 기록합니다. 단계마다 변화량과 바뀐 점수를 남기며, 마지막 단계의 점수가 최종 `score`와 같습니다. 결과 파일 스키마는 바뀌지 않습니다.
5. **조합 규칙 표** (`detector/combo_rules.py`): `lexicon`의 거래 조합 3개(던지기, 놀이터 검증업체, 메신저 가짜 인원)와 `precision_policy`의 제안(offer) 조합 9개를 코드 조건문에서 표로 옮겼습니다. 판정 결과는 그대로입니다. 키워드 화면에서 이 표를 편집하는 기능은 아직 없습니다.
6. **오탐 사냥 검사** (`tools/fp_hunt.py`): 공공 누리집에 흔한 낱말 200개로 띄어 쓴 두 낱말 조합 39,800개를 만들고, 꼬리말 2종과 판정 기준 2종(보이는 글·숨긴 글)으로 전수 판정합니다. 낱말 일부만 끌어다 맞춘 사전 낱말로 광고가 되면 오탐으로 셉니다. `tools/test_scoring_boundaries.py`가 이 검사와 개별 회귀 문구를 묶어 실행합니다.

## 남은 한계

- 경계 판단은 띄어쓰기에 기댑니다. 띄어쓰기 없이 한 낱말 안에 든 동음어('토토로', '오피스텔')는 기존 `_NON_GAMBLING` 같은 예외로 처리해야 합니다.
- `fp_hunt`의 낱말 목록은 직접 고른 개발 자료입니다. 실제 공공 누리집 문구를 대량으로 모아 넣는 검증은 하지 못했습니다.
- 수정 전후 비교는 로컬 개발 자료 기준입니다. 운영 오탐률을 측정한 것은 아닙니다.
- 기존 `훤히.exe`에는 이 변경이 포함되지 않습니다.

## 추가: 경계 보정이 만든 미탐과 같은 날 수정 (2026-10-19)

### 경계 보정의 회귀

개발 자료 밖의 우회 문구로 다시 확인한 결과, 위 띄어쓰기 경계 보정이 미탐 4건을 새로 만들었다. 수정 전 소스(HEAD)에서는 모두 잡혔다.

| 문구 | 수정 전 | 경계 보정 후 |
|---|:---:|:---:|
| 바카 라게임 가입 보너스 지급 텔레 @abcd1234 | 탐지 | 놓침 |
| 슬 롯머신 무료 쿠폰 지급 텔레 @abcd1234 | 탐지 | 놓침 |
| 카지 노게임 첫 입금 보너스 텔레 @abcd1234 | 탐지 | 놓침 |
| 출장 마사지샵 24시 010-1234-5678 | 탐지 | 놓침 |

'바카|라게임', '출장|마사지샵'은 오탐이던 '코카|인형', '출장|오피스'와 모양이 같다(앞 낱말은 전부, 뒤 낱말은 일부만 씀). 남는 글자('게임', '샵')가 사전에 없어 우연한 결합으로 처리됐다. 모양만으로는 둘을 가를 수 없다.

수정: 실제 연락처나 문자 위장이 있으면 띄어쓰기를 넘은 일치도 센다(`lexicon._match_detail`의 `loose`). 위 4건은 모두 연락처가 있어 다시 잡히고, 연락처가 없는 '가입 플랜 안내'·'첫 충전 무료 이벤트'는 계속 제외된다. 정상 공지에 휴대폰 번호가 함께 있으면 우연한 결합이 다시 셀 수 있다는 위험은 남는다.

### 같은 날 함께 바꾼 점수 규칙

- 품목(MEDIUM) 이름만 있고 광고 유도 낱말·신호가 하나도 없으며 품목 이름이 글의 절반이 안 되면 기준 아래로 누른다(상한 `품목 이름만 있고 거래·연락 단서 없음`). gb.go.kr 채용 신체검사서의 마약류 검사 항목이 대상이다. 품목 이름만 빽빽한 숨김 도배는 그대로 광고로 본다. 처음 검토한 '거래 단서가 없으면 광고 아님' 안은 도배 광고 10종 중 9종을, 낱말 밀도만 더한 안은 실제 수집 광고 4건을 놓쳐 버렸다.
- 병원·약국의 비급여 가격표·처방 안내(비급여·진료비·처방이 필요·전문의약품·의사 처방·약사와 상담·의약품안전)는 연락처·거래 표현·문자 위장이 없을 때 정상으로 본다. 낱말 하나('처방', '검사')가 아니라 안내 표현으로 좁혔다. 같은 낱말을 정상 문맥 감점으로 넓힌 실험에서는 실제 광고 미탐이 7개에서 13개로 늘었다.
- 위 사례와 같은 낱말의 정상·광고 최소 쌍 14개를 `tools/test_scoring_boundaries.py`의 `PairTest`에 넣었다.

- '실제 문구 (광고·정상 불일치) 0건'은 숨긴 글 기준이다. 보이는 글 기준으로는 실제 광고 '온라인 토토 카지노 가입시 3만원 쿠폰 드립니다.'를 놓친다. 이번 변경 전부터 있던 미탐이다.
- 판정 속도는 이후 규칙을 더하기 전 값이다.
- 전체 회귀 결과는 `_regress/fix5-*.log`에 남는다(이 절을 쓰는 시점에 실행 중).
