# 정상 문맥 감점 변경 보고

## 변경 범위

기존 작업 내역 위에 정상 문맥 감점 개선만 추가했습니다. 실행 파일 빌드, 실제 공공기관 누리집 탐지, 외부 배포는 수행하지 않았습니다.

- `detector/context_evidence.py`: 예방·교육, 피해·상담 지원, 경고·신고 안내, 단속·보도라는 네 의미군을 정의합니다. 단독 ‘예방·안전·주의’와 같은 의미군 반복은 추가 감점을 만들지 않습니다.
- `detector/lexicon.py`: 단어 개수에 따른 기존 최대 1.5점 감점을 의미군당 0.5점, 합계 최대 0.8점 감점으로 대체합니다. 원점수, 실제 감점, 의미군과 일치 표현을 판정 내역에 남깁니다. 거래 유도가 없는 정상 문맥의 점수 상한 규칙은 별도로 유지합니다. 따라서 정상 제외의 효과 전체를 ‘최대 0.8점’으로 해석해서는 안 됩니다.
- `detector/precision_policy.py`: 문장별 판단을 유지하면서 정상 안내 링크에도 문맥 감점을 한 번만 적용합니다. 실제 개인 연락처가 있거나 목적이 불명확한 제휴사이트 안내는 검토 후보로 보존합니다. 가입 혜택·가입코드·즉시 행동 유도를 예방 단어가 지우지 않도록 합니다.
- 기존 키워드 화면 설명을 새 동작에 맞게 변경했습니다. 감점 사유는 기존 판정 근거 경로를 이용합니다. 새로운 점수 대시보드나 자동 링크 신뢰 판정은 추가하지 않았습니다.
- `tools/data/context_corpus.json`, `tools/check_context_corpus.py`, `tools/test_context_discount.py`: 출처를 기록한 자료와 재현 가능한 오프라인 검사, 반복 감점·문장 범위·신고 문맥 회귀 검사를 추가했습니다.

## 자료와 비교

[시험 자료 설명](정상문맥_시험자료_20261018.md)에 출처와 라벨 기준을 기록했습니다. 공개 문서 5개에서 실제 원문을 짧게 발췌한 9건과 합성 문구 30건, 총 39건입니다. 실제 발췌 9건은 정상 7건과 검토 필요 2건이며, 합성 자료는 정상 10건·광고 14건·검토 필요 6건입니다.

아래 비교의 ‘수정 전’은 이번 요청 시작 시점의 소스 사본입니다. 사용자에게 이미 적용했던 이전 문맥 개선이 포함돼 있으며, Git HEAD와의 비교가 아닙니다.

| 기대 판정 | 문구 수 | 수정 전 기대 판정 일치 | 수정 후 기대 판정 일치 |
|---|---:|---:|---:|
| 정상 | 17 | 17 | 17 |
| 탐지 대상 광고 | 14 | 7 | 14 |
| 검토 필요 | 8 | 3 | 8 |
| 합계 | 39 | 27 | 39 |

각 문구를 일반 글과 숨김 글 기준으로 검사해 각각 78회 판정했습니다. 수정 전 기대 판정과 다른 결과 24회, 수정 후 0회입니다. 별도 검증셋이 아닌 개발 자료이므로 현장 정확도 또는 통계적 개선율로 해석할 수 없습니다. 특히 이 자료의 정상 17건은 수정 전에도 오탐이 없었습니다. 확인한 개선은 예방 단어로 인한 광고 누락과 애매한 안내의 확정 판정 방지입니다.

비교 상세는 `_regress/context-before.json`, `_regress/context-after.json`에 보관했습니다. 실제 사이트를 재방문하지 않아도 저장된 시험 문구로 재현할 수 있습니다.

전체 로컬 실행 중 정상 신고 안내, 교육 예시, 단속 보도가 오탐되는 문제를 찾아 문맥 규칙을 보완했습니다. 해당 문제를 단위 회귀 검사에 추가하고 관련 사이트를 재검사했습니다. 수정 과정의 실패 결과도 삭제하지 않았습니다.

표준 회귀 도구의 최초 전체 실행은 실패했습니다. 수정 사이트 재실행을 반영한 최종 집합을 이전 검증 결과(20261018-100856 및 testsite4 재검사 20261018-101521)와 대조하면 주요·추가 탐지 항목 모두 동일합니다. 오래된 `baseline.json`과는 기존 선택자 문자열 및 URL 구분 차이가 남아 `확인 필요`로 표시됩니다. 기준 파일을 덮어써서 통과 처리하지 않았습니다.

## 남아 있는 한계

- 규칙 기반 문맥 판정입니다. 복잡한 인용과 실제 권유가 섞인 모든 문장을 의미적으로 이해하지는 못합니다.
- 출처 주소와 링크 용도는 시험 자료의 검토 근거이며, 런타임에서 출처를 읽어 정답을 결정하지 않습니다. 링크 실제 목적지를 자동 검증하거나 공공기관 도메인 전체를 면제하지 않습니다.
- 점수 감점과 정상 문맥 제외는 별도 동작입니다. 원래 광고 근거와 검토 후보를 보존하며, 검토 후보는 제출용 위반 항목에 포함하지 않습니다.
- 독립된 사이트에서 추가 사례를 수집하고 사람이 라벨을 확인하는 후속 검증이 필요합니다. 기존 실제 광고 문구 시험의 알려진 미탐 3건은 이번 변경 범위에서 해결하지 않았습니다.
- 기존 `훤히.exe`에는 이 변경이 아직 포함되지 않습니다. 소스 실행에 적용된 상태입니다.
